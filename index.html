Calendar Sync

Personal, single-user tool. Last updated: October 28, 2026.

Calendar Sync is a small script that runs on its owner's own Windows computer. It reads the start and end times of meetings from the owner's desktop Outlook calendar and mirrors them as "busy" blocks into a separate calendar in the owner's personal Google Calendar, so that one calendar shows when the owner is busy. It is not offered to the public and has no other users.

Privacy Policy

What Google data the app accesses

The app requests only the Google OAuth scope https://www.googleapis.com/auth/calendar.app.created. With it, the app can create one secondary calendar and create, change and delete events in calendars that the app itself created. It cannot read or change any other calendar, email, contacts or files in the Google account.

What the app writes

Each event the app writes contains only a fixed title, a start and end time, a color, and an internal identifier used to keep the two calendars in sync. It never copies meeting subjects, descriptions, locations, attendees or conference links.

Where data is stored

The app has no server. The Google OAuth token is stored only on the owner's computer. Calendar data is processed in memory on that computer and written only to the owner's own Google Calendar. Nothing is sent to the developer or to any third party, and the app uses no analytics, advertising or tracking.

Sharing and Limited Use

Information received from Google APIs is not shared, sold or transferred to anyone. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data and revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the calendar the app created removes every event it wrote.
